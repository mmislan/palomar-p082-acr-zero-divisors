# Zero-divisor criteria for absolute concentration robustness

García Puente et al. ([arXiv:2401.00078v3](https://arxiv.org/html/2401.00078v3), Question 3.13) asked whether a unique positive zero-divisor value is necessary or sufficient for absolute concentration robustness (ACR) in at-most-bimolecular mass-action networks. Explicit networks with positive rational rates answer both questions negatively. A further three-species example shows that their candidate algorithm can miss a zero-divisor ACR value under an admissible elimination order, refuting the unrestricted elimination-order form of Conjecture 4.7. For block orders that compare the other species before the distinguished species, completeness is established: every real zero-divisor ACR value is returned when the finite basis consists of nonzero steady-ideal elements whose leading monomials cover the ideal. ACR includes existence of a positive steady state; zero-divisor values include coordinate differences lying in the steady-state ideal.
