# Counterexamples to the unique zero-divisor value criterion for absolute concentration robustness, and block-order completeness of the candidate algorithm

Michael Mislan

For a mass-action network, species i has absolute concentration robustness (ACR) with value α if a positive steady state exists and every positive steady state has x_i = α; call α a zero-divisor value if x_i − α lies in, or is a zero divisor modulo, the real ideal generated by the mass-action field. García Puente et al. asked whether, when every reactant and product complex has at most two molecules, a unique positive zero-divisor value is necessary or sufficient for ACR. Explicit networks with positive rational rates answer both negatively: one has ACR with value 2 without a unique positive zero-divisor value; another has a positive steady state and a unique positive zero-divisor value but no ACR. Their candidate algorithm returns the positive roots of a univariate Gröbner-basis element in t = x_i, or otherwise of the leading coefficients in ℚ[t]. For a three-species network with ACR value 1 in t, where t − 1 is a zero divisor, an admissible elimination order comparing the degree in t before completing the comparison of the other variables, with a certified reduced basis, does not return 1. For rational rates, a block order comparing the other variables first, and finitely many nonzero ideal elements such that the leading monomial of every nonzero ideal element is divisible by that of one of them, every ACR value of t that is a zero-divisor value is returned.
