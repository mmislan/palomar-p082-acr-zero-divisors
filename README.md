# Zero-divisor methods for absolute concentration robustness: completeness, positive geometry, and quantitative certificates

Michael Mislan

For mass-action networks whose complexes have at most two molecules, uniqueness of a positive value α for which x_i − α lies in, or is a zero divisor modulo, the steady-state ideal is neither necessary nor sufficient for absolute concentration robustness (ACR): explicit networks show ACR with two such values, and a unique such value without ACR. For rational rate constants, the Gröbner-basis candidate algorithm can miss a zero-divisor ACR value under a monomial order that is an elimination order but not a block order; an explicit reduced basis witnesses this. Under a block order, with a family of ideal elements whose leading monomials cover the ideal's, every real value that is both a nonvacuous ACR value and a zero-divisor value is a positive root of the univariate basis element or of some leading coefficient. A returned candidate need not be an ACR value.
